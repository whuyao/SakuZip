# YCompress ユーザーガイド

## 画面構成

YCompressには4つの画面があります。

- **圧縮と解凍**：項目を追加し、ワークフローを選んでキューを実行します。
- **ワークフロー**：内蔵ワークフローの使用やカスタムワークフローの作成を行います。
- **履歴**：現在のAppセッションで完了した項目を表示します。
- **設定**：出力フォルダの変更と対応形式の確認を行います。

すべての処理はこのMac上で完結します。アカウントは不要で、ファイルはアップロード
されません。[UrbanCompチームサイト](https://urbancomp.net)は、サイドバー、設定、
ヘルプメニューから開けます。

## 表示言語

YCompressは簡体字中国語、英語、日本語に対応し、既定ではmacOSの優先言語に従います。
YCompressだけに言語を指定する場合は、**システム設定 → 一般 → 言語と地域 →
アプリケーション**を開き、YCompressを追加して言語を選び、Appを再起動してください。

## ファイルを追加

次の方法を利用できます。

1. ファイルまたはフォルダを点線の領域へドロップします。
2. **ファイルを選択…**をクリックします。
3. 右上の**ファイルを追加**をクリックします。
4. **ファイル → ファイルを追加…**、または`Command-O`を使用します。
5. Finderでファイルを右クリックし、**このアプリケーションで開く → YCompress**を選びます。
6. 1つ以上のファイルを`YCompress.app`アイコンへドロップします。

画像、動画、一般ファイル、フォルダ、アーカイブを同じキューへ混在して追加できます。
同じパスは重複して追加されません。

iCloud Driveなどのクラウドファイルがまだダウンロードされていない場合、サイズは
**サイズ取得待ち（クラウドファイルをダウンロード中）**と表示されます。YCompressは
処理中に元ファイルサイズを再取得し、正の現在値を取得した後でのみ削減率・増加率を
計算します。

外部から開いたファイルは待機キューへ追加されますが、自動では開始しません。
ワークフローと出力先を確認してから**ワークフローを実行**をクリックしてください。

## スマート圧縮

スマート圧縮は既定のワークフローです。

- 画像はImageIOでリサイズ・再エンコードします。
- 動画はAVFoundationの互換プリセットでMP4へ書き出します。
- 一般ファイル、フォルダ、既存アーカイブは新しいZIPへまとめます。

スマート圧縮は既存アーカイブを自動解凍しません。解凍する場合は**安全に解凍**を
選んでください。

基本手順：

1. 1つ以上の項目を追加します。
2. **スマート圧縮**を選びます。
3. 出力フォルダを確認します。
4. **ワークフローを実行**をクリックします。
5. 完了後に虫眼鏡ボタンをクリックし、Finderで結果を表示します。

## 画像圧縮

内蔵の**Web画像**ワークフロー：

- 長辺を1920 pxに制限します。
- 既定でJPEGへ出力します。
- バランス品質を使用します。

JPEG、PNG、HEIC、HEIF、TIFF、BMP、GIF、WebPを認識しますが、実際のデコード対応は
macOSのバージョンに依存します。アニメーションGIF/WebPは先頭フレームのみになる
場合があります。透明度を保持するには、JPEGを強制せず「自動」またはPNGを選びます。

## 動画圧縮

内蔵の**動画共有**ワークフローは、元動画とシステムプリセットの推定出力サイズを比較し、
サイズ削減が見込める範囲で最も高品質な互換プリセットを選びます。出力はMP4で、
既定ではネットワーク再生向けに最適化されます。

解像度：

- **元の解像度を維持**：システムの最高品質プリセットを使用します。
- **最大1080p**：1080p以下の互換プリセットから選択します。
- **最大720p**：720p以下の互換プリセットから選択します。
- **最大540p**：540p以下の互換プリセットから選択します。

高品質、バランス、小さいサイズでは、推定出力サイズの上限が異なります。実際の出力が
元ファイルより小さくならない場合、その結果は削除されます。正確なビットレート、CRF、
音声トラック、字幕、エンコーダの指定には現在対応していません。AVFoundationが
デコードできないMKV、WebM、特殊なコーデックは失敗する場合があります。

## ファイル・フォルダのアーカイブ

**アーカイブ作成**を選ぶか、一般項目にスマート圧縮を使用します。

- キュー項目ごとに個別のZIPを生成します。
- フォルダは最上位フォルダ名を保持できます。
- 単一ファイルはZIPのルートへ配置されます。
- macOSリソースと拡張メタデータを保持できます。
- 既存の出力は上書きせず、必要に応じて`2`、`3`などを追加します。

複数の独立したキュー項目を1つのZIPへまとめる機能には現在対応していません。

## 安全な解凍

対応形式：

- ZIP
- TAR
- TGZ
- TAR.GZ

YCompressは解凍前にすべてのエントリパスを検査し、絶対パスと`..`を含むパスを拒否して
Zip Slipの危険を軽減します。7z、RAR、単一ファイルGZには対応していません。

## カスタムワークフロー

1. **ワークフロー**を開きます。
2. **新規ワークフロー**をクリックします。
3. 名前を入力します。
4. 操作と品質を選びます。
5. **作成**をクリックします。
6. カードの**使用**をクリックして処理画面へ戻ります。

カスタムワークフローはローカル設定へ保存されます。削除しても出力ファイルは
削除されません。

## ワークフローの詳細設定

ワークフローカードのスライダーボタンをクリックします。内蔵ワークフローも変更でき、
**デフォルトに戻す**で初期設定へ戻せます。

すべてのワークフロー：

- 出力ファイル名の接尾辞。
- 完了後にFinderで表示。
- 1項目が失敗した後もキューを続けるか停止するか。

画像：

- 出力形式：自動、JPEG、PNG、HEIC。
- 品質：高品質、バランス、小さいサイズ。
- 512〜8192 pxの長辺制限（任意）。

動画：

- 出力解像度：元の解像度、1080p、720p、540p。
- ネットワーク再生向け最適化。
- 推定出力サイズ上限を決める品質レベル。

ZIP：

- 最上位フォルダを保持。
- macOSリソースと拡張メタデータを保持。

解凍：

- アーカイブごとに個別フォルダを作成。
- オフにすると出力フォルダへ直接書き込みます。同名項目が置き換えられる場合があるため
  注意してください。

## 出力フォルダ

ファイル追加前の初期フォルダ：

```text
~/Downloads/YCompress
```

最初のバッチを追加すると、出力先は最初の元ファイルがあるフォルダへ変わります。
フォルダを追加した場合は、そのフォルダ自身の中へZIPを書かないよう親フォルダを
使用します。複数の場所から追加した場合は、最初の項目の元フォルダを共有します。

下部バーのフォルダボタンまたは設定から出力先を変更できます。既存キューへ追加しても、
手動選択した出力先は変更されません。同名の出力は上書きされません。

## キューの状態と操作

- **待機中**：まだ開始していません。
- **処理中**：ファイルごとの進捗率と処理段階を表示します。
- **完了**：出力が作成され、進捗は100%です。
- **失敗**：エラー内容を表示します。
- **キャンセル済み**：キャンセル時点の進捗率を保持します。

**キューを一時停止**は現在のファイルが安全に完了した後で停止します。
**キューを再開**は次の項目から続行します。**キャンセル**は動画書き出しを中止するか、
ZIP・解凍プロセスを終了します。画像は次の処理チェックポイントで停止します。

ImageIO、AVFoundationの書き出し、システムアーカイブツールのすべてが安全な途中停止に
対応しているわけではないため、一時停止は項目間で行います。これにより破損した出力や
不完全な出力を避けます。

虫眼鏡ボタンはタスクIDから最新の出力先を取得します。ファイルはFinderで選択され、
解凍フォルダは直接開きます。**結果を消去**は画面上の完了・失敗・キャンセル行だけを
削除し、ディスク上のファイルは削除しません。

## トラブルシューティング

### 動画の書き出しに失敗する

元動画をQuickTime Playerで再生できるか確認してください。QuickTimeでも開けない場合、
AVFoundationがそのコーデックに対応していない可能性があります。

### 圧縮後に大きくなる

すでに圧縮済みの画像やZIPは再処理で大きくなる場合があり、赤色で表示されます。
動画は書き出し前に分析され、元動画より小さくならない出力は自動的に削除されます。

### RARや7zを解凍できない

macOSにデコーダが含まれず、現在のYCompressは第三者製実行ファイルを同梱していません。

### 履歴が消える

履歴は現在のAppセッション中のみ保持されます。YCompressを終了しても出力ファイルは
削除されません。

### ファイルはアップロードされるか

いいえ。YCompress自体はネットワーク通信を行わず、すべてローカルで処理します。
