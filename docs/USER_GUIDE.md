# YCompress 使用手册

## 界面概览

YCompress 包含四个区域：

- **压缩与解压**：添加文件、选择工作流并运行任务。
- **工作流**：查看内置工作流，创建或删除自定义工作流。
- **处理记录**：查看本次 App 运行期间完成的任务。
- **设置**：修改默认输出目录并查看支持范围。

所有处理均在本机完成，不需要账号，也不会上传文件。

App 侧栏底部、设置页和“帮助”菜单中均可访问
[UrbanComp 团队网站](https://urbancomp.net)。

## 界面语言

YCompress 支持简体中文、English 和日本語。第一次启动默认跟随 macOS 的首选语言。
之后可在 YCompress 的“设置 → 语言”中选择“跟随系统”或指定语言；选择会保存在本机，
重新启动 App 后生效，以后启动会继续使用上一次设置的语言。

## 添加文件

可以使用以下任一方式：

1. 将文件或文件夹拖到虚线区域。
2. 点击“选择文件…”。
3. 点击右上角“添加文件”。
4. 使用菜单“文件 → 添加文件…”或快捷键 `Command-O`。
5. 在 Finder 中右键文件选择“打开方式 → YCompress”。
6. 将一个或多个文件拖到 `YCompress.app` 图标。

队列可以同时包含图片、视频、普通文件、文件夹和压缩包。重复路径不会被重复添加。

如果 iCloud Drive 或其他云盘文件尚未下载到本机，大小会暂时显示为
“大小待获取（云文件下载中）”。YCompress 会在处理期间重新读取源文件大小；下载完成后，
界面会更新为真实大小，并以该值计算节省或增大百分比。

从外部传入文件时，YCompress 会切换到“压缩与解压”页面并把文件加入等待队列，
但不会自动开始处理。请先选择工作流、检查输出目录，再点击“运行工作流”。

## 智能压缩

“智能压缩”是默认工作流：

- 图片使用 ImageIO 重新编码和缩放。
- 视频使用 AVFoundation 的兼容预设导出 MP4。
- 普通文件、文件夹和已有压缩包会创建新的 ZIP。

智能压缩不会自动解压压缩包。需要解压时请选择“安全解压”。

操作步骤：

1. 添加一个或多个项目。
2. 在“工作流”菜单中选择“智能压缩”。
3. 确认底部输出文件夹。
4. 点击“运行工作流”。
5. 完成后点击放大镜按钮，在 Finder 中显示结果。

## 图片压缩

内置“网页图片”工作流会：

- 将最长边限制为 1920 px。
- 默认输出为 JPEG。
- 使用均衡质量设置。

支持范围包括 JPEG、PNG、HEIC、HEIF、TIFF、BMP、GIF 和 WebP，但最终解码能力取决于
macOS 版本。动画 GIF/WebP 可能只保留首帧，不建议用当前版本处理重要动画素材。
如需保留透明通道，请在高级参数中选择“自动”或“PNG”，不要强制选择 JPEG。

## 视频压缩

内置“分享视频”工作流会先分析源视频与系统预设的预计输出大小，再选择能够减小文件且
画质尽可能高的兼容预设。输出为 MP4，并启用网络播放优化。

输出分辨率：

- **保持原分辨率**：使用系统最高质量预设。
- **最高 1080p**：从不超过 1080p 的兼容预设中选择。
- **最高 720p**：从不超过 720p 的兼容预设中选择。
- **最高 540p**：从不超过 540p 的兼容预设中选择。

“高质量 / 均衡 / 更小体积”会设置不同的预计输出上限。YCompress 优先选择上限内画质
最高的预设；若所选预设的实际输出仍不小于源文件，会自动删除该无效结果并提示用户。
当前版本不提供精确码率、CRF、音轨、字幕和编码器选择。无法被 AVFoundation 解码的
MKV、WebM 或特殊编码视频可能处理失败。

## 文件与文件夹归档

选择“归档打包”或使用“智能压缩”处理普通文件：

- 每个队列项目会分别生成一个 ZIP。
- 文件夹会保留顶层文件夹名称。
- 单个文件会直接放在 ZIP 根目录。
- macOS 资源信息会被保留。
- 可在高级参数中选择不使用密码、AES-256（推荐）或传统 ZIP 兼容密码。
- 如果输出文件已存在，会自动添加 `2`、`3` 等编号，不会覆盖旧文件。

当前版本尚不支持把多个独立队列项目合并到同一个 ZIP。

### 密码保护

启用密码保护后，YCompress 会在运行工作流时显示密码窗口。创建时需要输入并确认密码；
批量任务可选择在本次队列复用同一密码。密码不会保存到工作流、偏好设置、命令行参数
或日志，完成、取消或退出后会从任务内存清除。

- **AES-256（推荐）**：默认安全选项，适合 YCompress、WinZip、7-Zip 等支持
  WinZip AES 的工具。
- **传统 ZIP 密码（兼容模式）**：供旧工具使用，但安全性较弱，不适合敏感资料。

标准 ZIP 加密只保护文件内容，文件名和目录结构仍可能可见。加密 ZIP 保留常规文件时间
和权限；“macOS 资源与扩展元数据”仅适用于未加密 ZIP。建议使用至少 12 个字符的密码。

## 安全解压

支持：

- ZIP
- TAR
- TGZ
- TAR.GZ

操作步骤：

1. 添加压缩包。
2. 选择“安全解压”工作流。
3. 选择输出目录。
4. 点击“运行工作流”。

YCompress 会先检查压缩包内的路径，拒绝绝对路径以及包含 `..` 的路径，降低 Zip Slip
路径穿越风险，并检查可能逃逸目标目录的符号链接。加密 ZIP 会自动提示密码；密码错误
可以重新输入，错误或取消时不会保留半解压目录。7z、RAR 和单文件 GZ 暂不支持。
TAR、TGZ 和 TAR.GZ 格式本身不提供标准密码保护。

## 自定义工作流

1. 打开侧栏“工作流”。
2. 点击“新建工作流”。
3. 输入名称。
4. 选择操作和质量级别。
5. 点击“创建”。
6. 在工作流卡片上点击“使用”，App 会自动进入“压缩与解压”页面。

自定义工作流保存在本机偏好设置中。删除工作流不会删除任何输出文件。

## 工作流高级参数

点击任一工作流卡片右上角的滑杆按钮，可以编辑高级参数。内置工作流也可以调整，
修改会持久保存在本机；点击“恢复默认”可撤销该内置工作流的自定义设置。

所有工作流都支持：

- **输出文件后缀**：留空使用默认名称；填写后会替换默认的 `-compressed` 后缀。
- **完成后在 Finder 中显示**：每项任务成功后自动定位输出。
- **单个任务失败后继续队列**：关闭时，首次失败后停止本批次剩余任务。

图片工作流支持：

- **输出格式**：自动、JPEG、PNG 或 HEIC。“自动”会根据透明通道选择 PNG 或 JPEG。
- **质量级别**：高质量、均衡或更小体积。
- **限制最长边**：可在 512–8192 px 之间设置，或关闭尺寸限制。

视频工作流支持：

- **输出分辨率**：保持原分辨率、最高 1080p、最高 720p 或最高 540p。
- **针对网络播放优化**：调整 MP4，使在线播放更快开始。
- **质量级别**：控制预计输出体积上限，系统会在允许的分辨率内优先保留画质。

ZIP 归档工作流支持：

- **密码保护**：不使用密码、AES-256（推荐）或传统 ZIP 密码（兼容模式）。工作流只保存
  加密方式，密码始终在运行时询问。
- **文件夹保留顶层目录**：打开时，解压后仍包含原文件夹名称。
- **保留 macOS 资源与扩展元数据**：适合 Mac 间传输；关闭后更偏向跨平台兼容。
  启用密码时此选项不可用。

解压工作流支持：

- **为每个压缩包创建独立文件夹**：默认开启，避免不同压缩包内容混在一起。
- 关闭后会直接写入输出目录，同名项目可能被替换，请谨慎使用。

## 输出文件夹

尚未添加文件时，初始输出目录是：

```text
~/Downloads/YCompress
```

首次添加一批文件后，输出目录会自动改为第一个文件所在的文件夹；如果传入的是文件夹，
则使用该文件夹的上级目录，避免把输出写入待归档文件夹自身。来自多个不同目录的文件
共用第一项的来源目录。

点击底部文件夹按钮或打开“设置”可以随时更改当前输出目录。继续向已有队列添加文件
不会覆盖用户已经选择的输出目录。YCompress 不会覆盖同名结果。

## 任务状态

- **等待中**：尚未开始。
- **处理中**：显示当前文件的百分比进度和读取、缩放、写入、安全检查等阶段。
- **完成**：已经生成结果，进度显示 100%。
- **失败**：显示具体错误，后续队列任务仍会继续。
- **已取消**：用户取消了当前处理，保留取消前的百分比。

运行队列时还可以：

- 点击“暂停队列”：加密 ZIP 会在当前条目的数据块边界暂停；图片、视频和系统归档工具
  会在安全检查点或当前任务完成后暂停队列。
- 点击“继续队列”：继续当前加密归档任务或下一个等待项目。
- 点击“取消”：取消视频导出、终止系统归档进程或中止加密 ZIP；未完成输出会被清理。

YCompress 不会为了表现“暂停”而留下可被误认为完成的半成品。加密 ZIP 使用临时输出，
只有完整性校验通过后才移动到最终位置。

完成后点击放大镜查看结果。按钮会根据任务 ID 获取最新输出路径：普通文件会在 Finder
中被选中，解压得到的文件夹会直接打开。

“清理结果”会从当前界面移除完成、失败或已取消的记录，不会删除磁盘文件。

## 常见问题

### 视频导出失败

确认源视频可以在 QuickTime Player 中正常播放。若 QuickTime 也无法打开，通常表示
AVFoundation 不支持该编码。

### 压缩后文件反而更大

已经高度压缩的图片或 ZIP 再次处理可能不会减小，界面会用红色显示“增大”百分比。
视频会在导出前分析预计大小；若实际输出仍不小于源视频，YCompress 会自动删除无效
输出并提示“源视频已高度压缩”，不会再留下比原文件更大的视频。

若云盘文件刚加入队列时尚未下载，旧版本可能会保留 0 KB 的占位大小。0.1.6 起会在
读取和处理期间刷新源文件大小，只有取得大于 0 的真实值后才显示压缩率。

### 无法解压 RAR 或 7z

macOS 不自带对应解码器，YCompress 首版没有捆绑第三方二进制。后续版本可增加可选的
7-Zip helper。

### 忘记 ZIP 密码

YCompress 不保存密码，也无法恢复或绕过密码。请通过安全渠道保存或传递密码。AES ZIP
的文件名可能仍可见，这不代表文件内容已经解密。

### 历史记录消失

当前处理记录仅保留在本次 App 运行期间。退出 App 不会删除磁盘上的输出文件。

### 文件是否会上传

不会。除非用户自行打开 GitHub 下载页面，否则 YCompress 本身不执行网络请求。
