# YCompress 使用手册

## 界面概览

YCompress 包含四个区域：

- **压缩与解压**：添加文件、选择工作流并运行任务。
- **工作流**：查看内置工作流，创建或删除自定义工作流。
- **处理记录**：查看本次 App 运行期间完成的任务。
- **设置**：修改默认输出目录并查看支持范围。

所有处理均在本机完成，不需要账号，也不会上传文件。

## 添加文件

可以使用以下任一方式：

1. 将文件或文件夹拖到虚线区域。
2. 点击“选择文件…”。
3. 点击右上角“添加文件”。
4. 使用菜单“文件 → 添加文件…”或快捷键 `Command-O`。

队列可以同时包含图片、视频、普通文件、文件夹和压缩包。重复路径不会被重复添加。

## 智能压缩

“智能压缩”是默认工作流：

- 图片使用 ImageIO 重新编码和缩放。
- 视频使用 AVFoundation 的兼容预设导出 MP4。
- 普通文件、文件夹和已有压缩包会创建新的 ZIP。

智能压缩不会自动解压压缩包。需要解压时请选择“安全解压”。

操作步骤：

1. 添加一个或多个项目。
2. 在“工作流”菜单中选择“智能压缩”。
3. 确认底部输出文件夹。
4. 点击“运行工作流”。
5. 完成后点击放大镜按钮，在 Finder 中显示结果。

## 图片压缩

内置“网页图片”工作流会：

- 将最长边限制为 1920 px。
- 无透明通道的图片输出为 JPEG。
- 带透明通道的图片输出为 PNG。
- 使用均衡质量设置。

支持范围包括 JPEG、PNG、HEIC、HEIF、TIFF、BMP、GIF 和 WebP，但最终解码能力取决于
macOS 版本。动画 GIF/WebP 可能只保留首帧，不建议用当前版本处理重要动画素材。

## 视频压缩

内置“分享视频”工作流使用较小体积预设，输出 MP4，并启用网络播放优化。

质量级别：

- **高质量**：保持更高分辨率和画质。
- **均衡**：使用 1280 × 720 系统预设。
- **更小体积**：使用 960 × 540 系统预设。

当前版本不提供自定义码率、CRF、音轨、字幕和编码器选择。无法被 AVFoundation 解码的
MKV、WebM 或特殊编码视频可能处理失败。

## 文件与文件夹归档

选择“归档打包”或使用“智能压缩”处理普通文件：

- 每个队列项目会分别生成一个 ZIP。
- 文件夹会保留顶层文件夹名称。
- 单个文件会直接放在 ZIP 根目录。
- macOS 资源信息会被保留。
- 如果输出文件已存在，会自动添加 `2`、`3` 等编号，不会覆盖旧文件。

当前版本尚不支持把多个独立队列项目合并到同一个 ZIP。

## 安全解压

支持：

- ZIP
- TAR
- TGZ
- TAR.GZ

操作步骤：

1. 添加压缩包。
2. 选择“安全解压”工作流。
3. 选择输出目录。
4. 点击“运行工作流”。

YCompress 会先检查压缩包内的路径，拒绝绝对路径以及包含 `..` 的路径，降低 Zip Slip
路径穿越风险。7z、RAR 和单文件 GZ 暂不支持。

## 自定义工作流

1. 打开侧栏“工作流”。
2. 点击“新建工作流”。
3. 输入名称。
4. 选择操作和质量级别。
5. 点击“创建”。
6. 在工作流卡片上点击“使用”，然后返回“压缩与解压”。

自定义工作流保存在本机偏好设置中。删除工作流不会删除任何输出文件。

## 输出文件夹

默认输出目录是：

```text
~/Downloads/YCompress
```

点击底部文件夹按钮或打开“设置”可以更改输出目录。YCompress 不会覆盖同名结果。

## 任务状态

- **等待中**：尚未开始。
- **处理中**：当前正在处理。
- **完成**：已经生成结果。
- **失败**：显示具体错误，后续队列任务仍会继续。

“清理结果”只会从当前界面移除完成或失败的记录，不会删除磁盘文件。

## 常见问题

### 视频导出失败

确认源视频可以在 QuickTime Player 中正常播放。若 QuickTime 也无法打开，通常表示
AVFoundation 不支持该编码。

### 压缩后文件反而更大

已经高度压缩的图片、视频或 ZIP 再次处理可能不会减小。YCompress 会保留结果供比较，
但不会自动删除较大的输出。

### 无法解压 RAR 或 7z

macOS 不自带对应解码器，YCompress 首版没有捆绑第三方二进制。后续版本可增加可选的
7-Zip helper。

### 历史记录消失

当前处理记录仅保留在本次 App 运行期间。退出 App 不会删除磁盘上的输出文件。

### 文件是否会上传

不会。除非用户自行打开 GitHub 下载页面，否则 YCompress 本身不执行网络请求。
